# 二轴回转器仿真

直接用浏览器打开 `index.html`，无需安装依赖或联网。也可在此目录运行 `node server.cjs`，访问 `http://127.0.0.1:8765`。

- **匀速模式**：两轴转速均可手动输入小数，与滑块同步，范围 −10～10 rpm；负值反转，0 停转。数值输入立即生效，非法输入保留上次有效值；滑块步长为 0.01 rpm。默认外轴 1.33 rpm、内轴 2.00 rpm。
- **随机模式**：两轴独立在各自正负速度上限内均匀采样目标转速，从当前转速以设定加速度变化（默认 **0.01 rpm/s**）。两轴速度上限可手动输入 0.01～10 rpm，与滑块同步；加速度可手动输入 0.000001～10 rpm/s，支持小数。输入后立即生效，非法输入保留上次有效值。各轴达到自身目标后立即生成下一目标并连续追踪，不等待另一轴，也没有固定切换间隔或停留时间。切换到随机模式保留当前实际转速；随机模式重置后从 0 rpm 开始。更改上限后，实际转速连续变化，不会瞬间跳变。
- **随机种子**：使用固定伪随机序列；相同种子、模式、参数和初始状态，重置后可复现。更改种子时从新的序列生成下一个目标；点击重置从初始姿态开始复现。
- **控制**：暂停/继续、重置当前模式、自定义 0.01～1000 倍速（支持小数，输入后立即生效），也可选择常用倍率。无效输入会提示并保留上次有效倍率。倍率缩放仿真时间，不改变设定的加速度与采样间隔。重置保留参数、相机及运行/暂停状态，清空时间、轨迹、转速曲线、重力积分和覆盖率统计。
- **视图**：拖动旋转相机，滚轮缩放，透视/正视/俯视快捷视角，可开关旋转轴与轨迹。暂停时仍可调整相机。
- **读数**：角度以 [−180°, 180°) 显示，实际转速、样品局部 +Z 在世界坐标中的方向，以及最近 30 秒仿真时间的转速曲线。
- **重力评估**：计算旋转中心的重力在样品坐标系中的瞬时矢量 `gs = Rᵀ (0, −1, 0)`，以及从重置开始的累计平均 `ḡs = ∫gs dt / T`。以 `|ḡs| ≤ 0.001 g` 判断累计平均指标是否达标，同时显示矢量分量、累计时间及线性曲线（纵轴 0～1 g，刻度间隔 0.2 g）。平均矢量的模使用普通小数，保留六位小数。尚无时间数据时不显示假定的 0 g。
- **快进计算**：按当前运动参数计算额外 10 分钟的仿真，累积实际的运动与重力积分；保留运行/暂停状态。可以多次使用以评估长时间结果。更改模式或转速不清空累计数据，比较不同方案前请重置。
- **覆盖率**：重力评估下方显示累计覆盖率曲线与方向分布图。样品坐标系中的重力方向按经度 36 等分、Y 分量 18 等分划为 648 个等面积球面网格；覆盖率为已被采样的网格比例，纵轴 0～100%。方向每 0.05 秒仿真时间采样一次，独立于绘制帧率、倍率与快进；图中灰色表示未覆盖，已覆盖网格按当前最少至最多采样次数线性映射为浅黄 → 青绿 → 深蓝，提高次数差异的辨识度；图例显示实际次数范围。次数相同时统一显示青绿色，避免制造差异。颜色范围随累计数据更新，跨时刻比较应参考图例数值。橙色圆点为当前重力方向。指向网格可查看范围及计数。高覆盖率并不意味着方向分布均匀或平均重力达标；该估计依赖网格分辨率与采样间隔。
- **结果展示与导出**：点击“暂停并查看结果”查看截至当前仿真时间的累计平均重力曲线快照；关闭预览后可手动继续。可导出 1800 × 1120 像素的 PNG 图片和 CSV 数据，曲线采用线性纵轴与普通小数，包含 0.001 g 目标线。CSV 保存完整累计时段的记录点（约每 0.5 秒一个点，含当前终点），包含平均矢量模长、三分量、当时的实际转速、模式、速度上限、加速度、种子及覆盖率。在线曲线可压缩绘图点数，但 PNG/CSV 使用完整保存的记录。参数中途变化时，图片标注结束设置，CSV 保留各记录时刻的参数。预览中的两个导出按钮始终导出该快照，重置会清空当前记录。

曲线保存所有记录，绘制时按横向像素分段保留原始首末点、峰值和谷值，并按时间顺序连接。不会反复抽掉历史数据，也不使用平滑插值或移动平均来美化曲线。显示范围可选全程、最近 10 分钟或最近 1 分钟；纵轴可保持 0～1 g，或根据可见数据自动缩放，始终使用均匀线性刻度和普通小数。修改显示范围不会改变累计平均的起点。PNG 与预览遵循当前选定的显示范围及纵轴设置，CSV 始终导出全时段记录。

另有两张 X / Y / Z 三分量曲线：瞬时重力加速度曲线（每 0.1 秒仿真时间记录，默认显示最近 60 秒）与累计平均重力加速度曲线（从重置开始积分，约每 0.5 秒记录）。采用有正负值的均匀线性纵轴，平均曲线可自动缩放。可导出两图合并的 1800 × 1600 PNG；CSV 也包含记录时刻的瞬时 X / Y / Z。长时间全程展示会因有限像素而密集，可切换到最近 1 分钟查看实际振荡。

覆盖率区域还提供可拖动旋转的球面图，与展开图共用 648 个网格的采样计数和颜色；旋转视角不会改变统计。可用方向键旋转、按钮恢复初始视角，指向球面查看网格采样次数。当前重力方向在正面时为橙色实心圆，在背面时为空心圆及虚线。球面只显示当前视角的正面网格，可旋转查看其余方向。

## 运动模型

外框绕世界 X 轴旋转 α，内框绕外框的局部 Y 轴旋转 β，样品姿态为 `R = Rx(α) Ry(β)`。初始姿态为 α = 25°、β = −32°。内部转速与目标转速使用 rpm，角度使用度；**1 rpm = 6 °/s**，默认转速变化率 0.01 rpm/s 对应 0.06 °/s²。按转速曲线积分得到角度，在每个目标到达时刻精确切换。变化率按仿真时间计算，倍速播放不改变模型参数。样品中心保持固定；轨迹记录的是其局部 +Z 单位方向映射到显示球面后的路径，并非样品中心的空间轨迹。

页面用 Canvas 投影三维模型，并按面深度排序绘制。该工具为运动学演示，不包含电机动力学、机械碰撞检测、载荷或重力补偿计算。浏览器切换至后台时不补算后台时间。

## 模拟微重力的含义

双轴同时旋转可改变重力相对样品的方向，降低重力矢量的时间平均模长。但是，**瞬时重力的模长与其时间平均模长仍为 1 g**。`|平均矢量|` 很小，不等于 `平均模长` 很小，也不意味着重力被物理消除。这里的 10⁻³ g 是用户设定的累计平均评估目标，不是 ISS 环境的统一常数，也不是对实机的性能认证。

累计平均指标可能在完整旋转周期结束时达标，随后再次回升；达标不表示持续稳定。界面将小于 0.000001 g 的理想数值统一显示为 `< 0.000001 g`，避免将数值积分的舍入误差展示为物理精度。

ISS 的微重力与轨道自由落体有关，还受到振动等扰动影响。回转器是地面模拟方法，不能将上述平均指标直接等同于 ISS 的真实微重力。旋转中心之外的离心、欧拉、科里奥利加速度，以及介质流动与样品响应时间，需要另行建模或实测。

重力时间积分采用每段不超过 0.25 秒的四点 Gauss 求积。随机目标到达时精确切段，积分使用该段连续变化的转速与姿态。验证覆盖静止时平均 1 g、整周期双轴匀速时的解析抵消、随机加速度以及不同时间步的积分一致性。理想情况下，设置外轴 1 rpm、内轴 2 rpm，累计完整 60 秒周期可令平均矢量接近数值零；这只验证运动学积分，不证明各方向均匀覆盖或真实微重力效果。

资料：[RPM 运动学与局限的实验研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC13022057/)、[NASA 对微重力与自由落体的说明](https://www.nasa.gov/centers-and-facilities/glenn/what-is-microgravity/)、[NASA ISS 加速度环境指南](https://www.nasa.gov/humans-in-space/a-researchers-guide-to-acceleration-environment/)。

## 文件与检查

- `index.html`：页面结构
- `style.css`：响应式界面
- `simulation.js`：与界面无关的运动逻辑
- `app.js`：三维显示、控制与图表
- `simulation.test.cjs`：运动逻辑检查

有 Node.js 时运行 `node simulation.test.cjs`。

## 上传到 GitHub

将本文件夹中的文件上传到仓库根目录，让 `index.html` 位于根目录。预览截图和测试导出数据已排除；`.gitignore` 会忽略验证代码生成的图片、CSV 和 `node_modules`。

运行网页无需安装依赖；本地服务和运动逻辑检查只需要 Node.js。`browser-check.cjs` 是可选的浏览器验证脚本，需要安装 Playwright，并使用 Windows 默认安装路径下的 Google Chrome；其他环境需要调整脚本中的 `executablePath`。
